# Opinion Dynamics

Симулятор динамики мнений на случайном графе с упрямыми вершинами и эволюцией рёбер (появление и удаление).

## О модели

### Граф

Граф строится из нескольких уровней — обобщение модели «город–пригород» Эрдёша–Реньи на произвольное число групп. Уровень `i` содержит `nᵢ` вершин; любые две вершины внутри уровня `i` связаны ребром с вероятностью `pᵢ`. Между уровнями `i` и `j` вероятность связи — `min(pᵢ, pⱼ)`.

### Упрямые вершины

Упрямая вершина создаётся как новая вершина со степенью 1 — она прикрепляется ровно одним ребром к одной из вершин графа (случайно выбранной либо указанной явно) и навсегда хранит мнение 1.

### Мнения

Мнение каждой вершины — бинарное (0 или 1). На каждом шаге для каждой обычной (не упрямой) вершины `j` вычисляется доля единиц среди соседей:

    x_j = c_j / d_j

где `c_j` — число соседей с мнением 1, `d_j` — степень вершины `j`. По кусочно-линейной функции с порогами `k1 < k2` вычисляется вероятность перехода в состояние 1:

    f(x) = 0,                    если x <= k1
    f(x) = (x - k1) / (k2 - k1), если k1 < x <= k2
    f(x) = 1,                    если x > k2

Обновление синхронное: все вершины на шаге `t` смотрят на состояние графа и мнений на шаге `t-1`.

### Динамика рёбер

Если включена, на каждом шаге `t` вероятность появления нового ребра пересчитывается как `p(t) = p0 + k·t` (с ограничением в [0, 1]), и каждая пара вершин без ребра может его получить с этой вероятностью.

Отдельно, независимо, можно включить удаление рёбер — по той же схеме, со своими параметрами `removeP0`, `removeK`: для каждой существующей пары с вероятностью `removeP(t) = removeP0 + removeK·t` ребро может быть удалено.

## Запуск

    ./build/opinion_dynamics

Программа интерактивная — задаёт вопросы по очереди и читает ответы из stdin.

### Порядок диалога

**1. Способ получения графа:**
- `1` — сгенерировать новый граф
- `2` — загрузить граф из файла

**Если генерация — способ задания уровней:**
- `1` — ручной: количество вершин и вероятность вводятся отдельно для каждого уровня
- `2` — общий: одно число вершин и одна вероятность сразу для всех уровней

**Упрямые вершины** — `y`/`n`. Если `y`:
- сколько упрямых вершин добавить
- прикрепить вручную (указав номер вершины для каждой упрямой) или случайно — при ручном режиме и более чем 100 упрямых вершинах программа автоматически переключится на случайный с предупреждением

**Динамика рёбер** — `y`/`n`. Если `y`:
- начальная вероятность добавления `p0` и коэффициент `k`
- отдельно — нужно ли удаление рёбер (`y`/`n`), и если да — `removeP0`, `removeK`

**Пороги модели мнений:** `k1` (0.0..1.0), затем `k2` (не меньше `k1`, до 1.0)

**Количество шагов симуляции** — от 1 до 100000

**Seed генератора случайных чисел** — задать вручную (для воспроизводимости) или оставить случайным

**Если загрузка из файла:** программа читает граф и, если в файле сохранены параметры симуляции, предлагает использовать их как есть или ввести свои заново.

После диалога программа генерирует (или загружает) граф, выводит его статистику, прогоняет симуляцию на `T_MAX` шагов и печатает число вершин с мнением 1 и число рёбер: подробно на первых 100 шагах, затем каждые 50 шагов.

## Результаты прогона

Каждый запуск создаёт папку `runs/run_<seed>/` с тремя файлами:

- **`graph_initial.txt`** — граф перед симуляцией, вместе с параметрами запуска (секция `PARAMS`)
- **`graph_final.txt`** — граф после всех шагов симуляции
- **`simulation_log.txt`** — полная история:
  - параметры запуска (`SEED`, `T_MAX`, `K1`, `K2`, `DYNAMIC_EDGES`, `P0`, `K`, `REMOVE_EDGES`, `REMOVE_P0`, `REMOVE_K`)
  - ссылки на файлы графов (`INITIAL_GRAPH_FILE`, `FINAL_GRAPH_FILE`)
  - `HISTORY` — по строке на шаг: число вершин с мнением 1 и число рёбер
  - `OPINION_CHANGES` — построчно: шаг, вершина, было, стало — для каждой вершины, сменившей мнение
  - `EDGE_EVENTS` — построчно: шаг, `ADD`/`REMOVE`, первая вершина, вторая вершина, вес
  - `FINAL_OPINIONS` — финальное мнение каждой вершины

Повторный запуск с тем же seed, тем же графом и теми же параметрами даёт идентичный результат — это позволяет воспроизвести и проверить любой прогон.

## Формат файла графа

Текстовый, с секциями:

    VERTICES 155
    STUBBORN 5
    3
    17
    42
    88
    120
    EDGES 1189
    0 5 0.287298
    0 6 0.857518
    ...
    PARAMS
    SEED 42
    T_MAX 500
    K1 0.1
    K2 0.5
    DYNAMIC_EDGES 1
    P0 0.05
    K 0.001
    REMOVE_EDGES 0
    REMOVE_P0 0.0
    REMOVE_K 0.0

Секция `PARAMS` присутствует только в файлах, сохранённых через `saveGraphWithParams` (это `graph_initial.txt`); `graph_final.txt` сохраняется обычным `saveGraph`, без параметров. При загрузке любого из файлов `loadGraph` читает только `VERTICES`/`STUBBORN`/`EDGES`, а `loadGraphWithParams` дополнительно ищет `PARAMS`.

## Количество шагов симуляции

Число шагов (`T_MAX`) задаётся при каждом запуске через диалог, а не зашито в коде. Ориентировочные значения:

- 50 — быстрая проверка, что всё работает
- 500 — большинство экспериментов
- 5000–10000 — для наблюдения медленной динамики

При загрузке графа из файла с сохранёнными параметрами значение `T_MAX` восстанавливается автоматически вместе с остальными настройками.

## Что влияет на результат

- **k1** — порог, ниже которого смена мнения не происходит вообще. Если `k1` больше, чем `1 / средняя степень графа`, одиночная упрямая вершина не может «заразить» соседа, и система застревает в начальном состоянии.
- **k2** — порог, выше которого смена мнения гарантирована. Должен быть строго больше `k1`.
- **p0, k** — скорость роста плотности рёбер во времени. При `k = 0` плотность не растёт, даже если динамика включена.
- **removeP0, removeK** — аналогично, но для вероятности удаления существующих рёбер.
- **seed** — при одинаковом графе, параметрах и seed результат симуляции полностью детерминирован и воспроизводим.

## Известные ограничения

- Общий лимит вершин (включая упрямые) — 20 000
- На каждом шаге динамика рёбер перебирает все пары вершин графа; на больших графах (тысячи вершин) с включённой динамикой симуляция может занимать заметное время
